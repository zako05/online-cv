Michal Zak Online CV MCP Server & CLI Integration

Connect AI assistants (such as Claude Desktop, Cursor, or custom MCP clients) and CLI tools to Michal Zak Online CV using the Model Context Protocol (MCP) or standard HTTP tools.

MCP Configuration (Fetch Server)

Any MCP-compatible client can read Michal Zak's CV using the official @modelcontextprotocol/server-fetch or mcp-server-fetch tool pointed at the Markdown or JSON API endpoints: 

{
  "mcpServers": {
    "online-cv-fetch": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-fetch"]
    }
  }
}
