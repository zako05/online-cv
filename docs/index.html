Michal Zak Online CV API Documentation

Michal Zak Online CV provides static, zero-authentication HTTP endpoints in JSON, Markdown, and llms.txt formats so AI agents, crawlers, and developer tools can programmatically inspect work experience, technical skills, education, and certifications.

Base URL

{{ site.url }}{{ site.baseurl }}

API & Machine-Readable Endpoints

  • GET {{ site.baseurl }}/api/cv.json — Structured JSON API returning profile metadata, contact links, career summary, work experiences, technical skills, education, certificates, and languages.
  • GET {{ site.baseurl }}/openapi.json — OpenAPI 3.0.3 specification for the Online CV API.
  • GET {{ site.baseurl }}/index.md — Full curriculum vitae formatted in clean Markdown.
  • GET {{ site.baseurl }}/llms.txt — Standard llmstxt.org index file linking all primary resources and documentation.
  • GET {{ site.baseurl }}/llms-full.txt — Comprehensive plain-text/Markdown context bundle.
  • GET {{ site.baseurl }}/sitemap.xml — XML Sitemap listing all canonical URLs.

Example Request

curl -sS {{ site.url }}{{ site.baseurl }}/api/cv.json

Markdown Content Negotiation

Agents requesting Accept: text/markdown can retrieve Markdown directly from the homepage or via the explicit .md endpoints: 

curl -sS -L -H "Accept: text/markdown" {{ site.url }}{{ site.baseurl }}/
curl -sS -L {{ site.url }}{{ site.baseurl }}/index.md
